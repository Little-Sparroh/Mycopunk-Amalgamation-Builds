Carver Guide

Picture-led walkthrough for the Carver unlock chain: mission selects, parkour, broken parts, then the HUB finish.

At a glance

  1. Titan City — parkour & broken frame
  2. Gravity Farms (Singularity) — broken part
  3. Flourishing Desert — broken part
  4. Moldy Tundra — broken part
  5. HUB — server room part
  6. Build & claim Carver

How to use this guide

  • Work the steps in order — each broken part feeds the frame.
  • Match the location shot to your minimap; open the detail image if the pin is unclear.
  • Singularity missions keep a permanent map layout — use the example shot when the select screen is hard to read.

1. Titan City — parkour & broken frame

Mission select: Titan City

Parkour building

  • Run the parkour building → parkour course → boss arena path.
  • Claim the broken frame at the end of this leg before leaving Titan City.

2. Gravity Farms (Singularity) — broken part

Mission select: Gravity Farms · variant: Singularity

  • Drop into Gravity Farms on the Singularity layout.
  • Grab the broken part, then leave when the objective is done.

3. Flourishing Desert — broken part

Mission select: Flourishing Desert

  • Claim the broken part marked on the map shot above.

4. Moldy Tundra — broken part

Mission select: Moldy Tundra

  • Claim the broken part marked on the map shot above.

5. HUB — server room part

Location: HUB · Server room

  • Back in the HUB, open the server room.
  • Claim the last broken part for the frame.

6. Build & claim Carver

  • Build the broken frame into Carver once every part is collected.
  • Claim Carver when the craft finishes.

Notes

  • Mission-select screenshots are examples of the permanent map UI where it matters (especially Singularity).
  • If a pin looks off after a game update, trust the in-mission objective marker and treat the still as a region hint.
  • Still images live in Mycopunk-Abomination-Image-Repo under carver_guide_images/. The parkour course is embedded from YouTube.
