Picture-led walkthrough for the **Carver** unlock chain: mission selects, parkour, broken parts, then the HUB finish.

## How to use this guide

- Work the steps **in order** — each broken part feeds the frame.
- Match the **location shot** to your minimap; open the detail image if the pin is unclear.
- **Singularity** missions keep a permanent map layout — use the example shot when the select screen is hard to read.
