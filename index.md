# Home page notes (source for index.html hub)

Personal testing for the relative balance of Mycopunk.

## Pitch
- Builds ranked by kill time vs Amalgamation on **Threat 6** (game balance target per Liam).
- Personal testing — not every weapon tested equally.

## Methodology
- Timer starts the exact frame the Amalgamation spawns (mod-assisted).
- Setup/charge time is included in kill times (no free pass for long wind-ups).
- **Tool-assist in dataset:** Livewire-based builds and Gunship Cannon builds.
- Build page tiers come from kill times.
- **Weapon tierlist is a different dataset** — feel-based, bias toward horde clear AND bossing.
- Preference bias: weapons I dislike are under-tested.
